# Release Notes: v1.0.0

## Included

- Versioned fraud detection training and evaluation pipeline.
- SHAP explainability and model reporting.
- JWT-protected FastAPI serving with single, batch, and CSV prediction.
- Streamlit dashboard.
- Docker and Compose packaging.
- Automated quality and behavior tests.
- GitHub Actions quality workflow.
- Runtime metrics, security headers, request IDs, rate limiting, drift reports, and benchmarks.

## Scope Boundary

Cloud deployment, CI/CD deployment, monitoring infrastructure, and drift response automation remain operational extensions beyond this repository release.
